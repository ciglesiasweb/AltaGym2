# AltaGym — Producto

## Visión

AltaGym es una aplicación interna para un único gimnasio, AltaGym, ubicado en Rivas. No es una plataforma multiempresa ni se venderá inicialmente a otros gimnasios.

## Objetivo del MVP

Permitir que los clientes:

1. Consulten las clases grupales programadas.
2. Reserven plazas en clases grupales.
3. Reserven sesiones privadas con un monitor.

También debe permitir que el personal de recepción y administración mantenga la operativa diaria de forma sencilla. Ambos puestos comparten el mismo rol y los mismos permisos en el MVP.

## Principio rector

La simplicidad prevalece sobre la flexibilidad:

- Solo se incluye lo imprescindible para consultar, reservar y gestionar actividades.
- Se elige la alternativa con menos pasos y configuración.
- No se crean funciones “por si acaso”.
- Las excepciones y automatizaciones no imprescindibles se aplazan.

## Usuarios

- Recepción y administración, como un único rol funcional.
- Monitores.
- Clientes.

## Alcance

- Acceso mediante usuario y contraseña.
- Gestión de clientes y monitores.
- Disciplinas de monitores.
- Programación semanal de clases grupales.
- Reservas y cancelaciones grupales.
- Reservas y cancelaciones privadas.
- Bloqueos de monitores mediante el cliente especial «AltaGym».
- Backoffice operativo de recepción y administración.
- Agenda de solo lectura para monitores.
- Notificación opcional al cancelar una sesión.

## Fuera de alcance

- Pagos, cobros, facturación e impagos.
- Autorregistro de clientes.
- Recuperación automática de contraseña por correo o SMS.
- Lista de espera.
- Historial de reservas pasadas para clientes.
- Gestión manual de disponibilidad o ausencias de monitores.
- Gestión de limpieza o personal técnico como roles separados.
- Plataforma para varios gimnasios.

## Métricas iniciales pendientes

Las métricas concretas se definirán tras validar el MVP con el personal y los clientes del gimnasio.
